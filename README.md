# Проектування та реалізація об'єктно-орієнтованих систем в Python з використанням класів і спадковості

В лабораторнії роботі було досліджено проектування та реалізації об'єктно-орієнтованих систем мовою Python: визначення класів з атрибутами та методами, побудова класових ієрархій через наслідування, застосування інкапсуляції та поліморфізму, використання абстрактних класів і композиції.

# Структура проєкту 

* task 1: Класова ієрархія з наслідуванням та поліморфізмом 
* task 2: Інкапсуляція, property та контроль доступу
* task 3: Магічні методи та перевантаження операторів
* task 4: Абстрактні класи та композиція
* task 5: Паттерн проектування: реалізація та обґрунтування

# Інструкція з запуску

Для запуску необхіден Python 3.8 або новішої версії.
